Read the prices correctly

  • Sequencer: Advertises $40 per active stream hour. The session quote is authoritative. Viva includes built-in LLM world direction. Custom Genesis LLM requests and extra image/audio generation are separately metered. Worldstreams API, Genesis integration.
  • fal H3 Max Director: Bills generated video, with a 60-second minimum. Public sessions currently have a 15-minute ceiling. Director pricing and session limits.
  • Reactor: Bills wall-clock time while a session holds a GPU, including ready-but-idle time and recoverable disconnects. Use the session quote to confirm the applicable rate. Billing rules, current pricing API.

The planned Orbis Stable route is estimated at $40.16 per session hour. Viva is $40 per active stream hour, with built-in LLM direction. The billing clocks differ, so compare the session quote and your usage pattern. A complete experience also needs state storage, user access, LLM logic and audience billing. Read about those responsibilities in the host authority guide.

Read the timing correctly

Startup latency is the time from requesting a session to seeing its first usable frame. Response latency is the time from sending an action to seeing its effect. Generation speed describes how quickly video is produced. Chunk duration describes when a streaming model can accept a new direction.

The timing column reports the measure each provider publishes. It is not a common end-to-end latency benchmark. Queuing, network delivery, buffering and your controller can change the wait a player experiences.

Quality ratings

GENESIS uses a 1–5 rating for each of five criteria. The overall quality score is their mean, shown to one decimal place. Speed and price are reported separately.

Criterion What to check
Visual detail Clear subjects, readable environments and visible artifacts.
Prompt adherence Whether the requested action, setting and constraints appear.
Character consistency Whether identities, clothing and objects remain recognizable.
Scene continuity Whether locations, spatial relationships and previous events carry forward.
Motion and stability Natural movement, temporal consistency and recovery after a direction change.

Use 1 for major failures, 2 for frequent failures, 3 for a usable result, 4 for a consistently strong result and 5 for a reliably excellent result across the test set.

Score at least ten shared scenarios, run each three times for two minutes, and publish the prompts, model/version, resolution, settings, date and recordings. Include the same character, inventory and scene-transition challenges for every model. Have at least two reviewers score recordings without provider labels.

No matched GENESIS benchmark has been completed. Every model is currently unrated, including Sequencer. A provider's demo or a clip-generation leaderboard does not establish its score for a persistent interactive world.

Latency and moderation

Gemini 3.8 Flash supports a low thinking level. DeepSeek V4.1 Flash supports non-thinking mode. Claude Haiku 5.5 supports adaptive thinking and is designed for latency-sensitive tasks. Response time depends on the prompt, settings and route. Structured JSON needs to finish and pass validation before GENESIS can apply it. None of these models has a matched GENESIS latency benchmark.

Google exposes adjustable safety filters alongside persistent core protections. DeepSeek's moderation controls have not been verified for this comparison. Your host's content policy also applies.

  • DeepSeek model details and pricing confirm the V4.1 Flash version, non-thinking mode and peak/off-peak billing. The API model name is deepseek-flash.
  • Claude Haiku 5.5 model details and pricing confirm its adaptive thinking and prompt-length price tiers. The API model name is claude-haiku-5-5. Claude stop reasons describe safety refusals.

Sources and model details

  • Sequencer Viva tutorial and Worldstreams API. Viva specifications follow Sequencer's published product material; available deployments and stream quotes can change.
  • fal H3 Max Director. This is the streaming endpoint. The H3 Max image-to-video endpoint returns clips and has its own pricing.
  • Reactor MiniMax FastH3 specifications. Its published 1× real-time generation rate describes throughput, not time to the first frame.
  • Reactor Orbis Stable specifications. It generates 832 × 480 frames and upscales the delivered stream.
  • Reactor Orbis Dynamic specifications. Its current model card lists 640 × 368 native frames. The shared API overview lists a different raster, so confirm the selected deployment's output before choosing it for resolution-sensitive work.
